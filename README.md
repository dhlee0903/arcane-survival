# 먼 곳의 횃대 (Distant Roost)

**[바로 플레이 →](https://dhlee0903.github.io/arcane-survival/)**

**리스크 오브 레인 2**를 뱀서식 생존 게임으로 옮긴 것. 조작은 **이동뿐**이고 공격은 전부
자동으로 나간다. 몬스터를 잡아 경험치를 모으고, 레벨업 때마다 카드 세 장 중 하나를 골라
빌드를 쌓는다. **15분을 버티면 클리어.**

- **생존자** — 코만도 (다른 생존자 추가 예정)
- **무대** — 먼 곳의 횃대 (다른 무대 추가 예정)

의존성 제로 — 프레임워크도 빌드 도구도 쓰지 않는다. HTML · CSS · Vanilla JS(ES 모듈)뿐이다.
그래픽은 도트. 모든 그림은 소스에 문자열 픽셀맵으로 들어 있고 시작할 때
**스프라이트시트(아틀라스) 한 장으로 구워서** 거기서 잘라 쓴다. 이미지 파일은 하나도 없다.

## 실행

ES 모듈은 `file://`에서 로드되지 않으므로 정적 서버로 띄운다.

```bash
npx serve .
# 또는
python -m http.server 8000
```

## 조작

| 입력 | 동작 |
| --- | --- |
| 방향키 · WASD | 이동 |
| 화면 끌기(모바일) | 누른 자리에 가상 스틱이 생긴다 |

## 화면

게임판이 **창을 꽉 채운다.** 논리 해상도는 고정이 아니라 `창 크기 ÷ ZOOM`으로 정해져,
세로 폰은 세로로 길고 PC는 가로로 넓은 화면이 된다(`config.js`의 `setView`).
작은 화면은 2배, 큰 화면은 3배로 확대해 도트가 또렷하게 커 보인다.

화면이 좁아지면 같은 수의 적이 훨씬 빽빽해지므로, 소환량과 적 상한을 보이는 넓이에
비례해 조절한다(`areaScale`). 어떤 기기에서도 화면당 적 밀도는 같다.

## 코만도

원작의 스킬 구성 그대로다 — **주 무기 · 보조 · 이동기 · 특수**. 조준 버튼이 없으니 표적은
코드가 고르지만, **쏘는 방식**은 원작을 따랐다. 두 발씩 끊어 쏘고, 관통하고, 부채꼴로
퍼붓고, 던지고, 구른다.

| 스킬 | 방식 |
| --- | --- |
| 더블 탭 | 가장 가까운 적에게 **두 발씩 끊어** 쏜다 (원작 2×90%) |
| 페이즈 라운드 | 관통탄 한 발 · 줄지어 선 적을 통째로 꿴다 (원작 300% 관통) |
| 제압 사격 | 한 방향으로 탄을 퍼붓는다 · 맞은 적은 밀리고 비틀거린다 |
| 파편 수류탄 | 적 한가운데로 **던진다** · 떨어진 자리가 터지고 불이 남는다 |
| 택티컬 다이브 | 적이 붙으면 굴러 빠져나간다 · **구르는 동안 무적** |

**아이템** (최대 5개 · 각 6레벨) — 수치만 올려 주는 건 둘뿐이고, 나머지는 **때릴 때마다
굴리는** 것들이다(원작의 프록). 같은 스킬을 써도 무엇을 들었느냐에 따라 화면이 달라진다.

| 아이템 | 효과 |
| --- | --- |
| 크로우바 | 체력 90% 이상 적에게 피해 +75% |
| 폴의 염소 발굽 | 이동 속도 +14% |
| 곰 인형 | 피해를 통째로 막을 확률 +15% (중첩할수록 늘지만 100%엔 닿지 않는다) |
| 군인의 주사기 | 공격 속도 +15% |
| 우쿨렐레 | **타격 시 25% 확률로 번개가 튄다** |
| AtG 미사일 Mk.1 | **타격 시 10% 확률로 유도 미사일** |
| 렌즈 제작자의 안경 | 치명타 확률 +7% (치명타는 피해 2배) |
| 몬스터의 이빨 | 처치 시 회복 구슬을 떨군다 |

**대체 스킬** — 원작의 얼터네이트 스킬을 이 판의 규칙으로 옮겼다.
**스킬을 Lv6까지 올리고 + 짝이 되는 아이템을 갖춘 뒤 + 상자를 열면** 그 스킬이 바뀐다.

| 스킬 (Lv6) | 필요한 아이템 | 대체 스킬 |
| --- | --- | --- |
| 더블 탭 | 크로우바 | **크라우드펀더** — 멈추지 않고 난사 |
| 페이즈 라운드 | 군인의 주사기 | **페이즈 블래스트** — 관통탄을 부채꼴로 여덟 발 |
| 제압 사격 | AtG 미사일 | **일회용 미사일 발사기** — 유도 미사일 열두 발 |
| 파편 수류탄 | 곰 인형 | **거대한 광휘** — 수류탄 네 발 · 불바다 |
| 택티컬 다이브 | 폴의 염소 발굽 | **택티컬 슬라이드** — 더 멀리, 지나친 적을 벤다 |

## 먼 곳의 횃대

안개 낀 바닷가 절벽. 이끼 낀 바위 바닥에 그루터기 · 버섯 · 무덤이 흩어져 있다.

| 몬스터 | 공격 |
| --- | --- |
| 레무리안 | 기본 적. 멈춰 서서 조준한 뒤 불덩이를 뱉는다 |
| 레서 위습 | 거리를 두고 떠다니다 **1.6초 조준 후 불덩이 세 발** (원작과 같다) |
| 해파리 | 제일 빠르다. **닿으면 몸을 터뜨리고 사라진다** |
| 비틀 | 조준 없이 그냥 달려든다 |
| 비틀 가드 | 엘리트. **발밑으로 곡사 세 발** — 떨어질 자리가 보이니 비켜서면 된다 |
| 스톤 타이탄 | 보스. 눈이 달아오른 뒤 **굵은 광선** — 예고가 길어서 옆으로 빠지면 피한다 |

**적도 쏜다.** 접촉 피해만 있으면 그냥 몰려오는 벽이라, 피할 것이 있어야 이동이 의미를
갖는다. 모든 원거리 공격은 **조준 시간(예고)** 을 두고, 원거리형은 일정 거리 안으로는
더 붙지 않는다. 적탄은 주황, 내 탄은 노랑으로 색을 갈라 뒀다.

원작 수치를 그대로 옮기면(레무리안 80 · 타이탄 2100) 이쪽 밀도에서는 벽이 된다.
**서열과 성격만** 가져왔다 — 해파리가 제일 빠르고 자폭하며, 위습이 가장 약하다.

**진행** — 시간대별로 몬스터 구성과 소환 간격이 바뀐다. 중간중간 포위 · 무리 · 엘리트가
끼어들고 5 · 10 · 14분에 스톤 타이탄이 나온다. 엘리트와 보스는 상자를 떨구고,
상자를 열면 대체 스킬(조건이 맞으면)이나 스킬 강화가 일어난다.

**배럴과 금화** — 들판에 배럴이 띄엄띄엄 놓인다. 맞으면 부서지고 금화 · 회복 · 자석 중
하나가 나온다. 금화는 판이 끝나면 누적 기록으로 쌓인다.

**기록** — 생존 시간과 누적 금화를 localStorage에 남긴다.

## 디버그 콘솔

마우스가 있는 기기에서만 만들어진다(`pointer: fine`). `` ` `` 또는 F1로 열고 닫는다.

- **읽기** — fps · 프레임 시간 · 한 스텝 처리 시간, 남은 시간, 논리 해상도 · 확대 배율 ·
  넓이 배율, 체력 · 레벨 · 경험치 · 처치 수 · 좌표, 개체 수, 가진 것과 보정치
- **시간** — 정지 · 0.25x · 1x · 2x · 4x, 한 스텝씩 넘기기
- **치트** — 무적, 즉시 레벨업, 스킬 · 아이템 만렙, 회복, 상자
- **소환** — 보스 · 엘리트 · 떼거리(40마리 포위) · 전멸
- **보기** — 히트박스(실제 판정 원), 스프라이트시트
- **+1분** — 시간을 건너뛴다. 지나친 사건은 몰아서 터지지 않고 지나간 것으로 처리한다

게임 로직은 건드리지 않는다. 콘솔을 지워도 게임은 그대로 돈다.

## 구조

```
├── index.html          # 마크업 + 오버레이(타이틀 · 레벨업 카드 · 일시정지)
├── css/style.css
├── src/
│   ├── config.js       # 상수 (single source of truth)
│   ├── sprites.js      # 픽셀맵 · 팔레트 · 스프라이트시트 굽기 · 5×7 도트 글꼴
│   ├── anim.js         # 애니메이션 클립과 프레임 진행
│   ├── weapons.js      # 스킬 정의(레벨표) + 발사 로직
│   ├── upgrades.js     # 아이템 정의 + 레벨업 카드 뽑기
│   ├── spawner.js      # 시간대별 소환과 사건(포위 · 엘리트 · 보스)
│   ├── game.js         # 상태와 규칙 (그리지 않는다)
│   ├── renderer.js     # 읽기 전용 렌더러 (아틀라스에서 잘라 그린다)
│   ├── input.js        # 키보드 + 가상 스틱
│   ├── storage.js      # 최고 기록
│   ├── debug.js        # PC 전용 디버그 콘솔(게임 로직 밖)
│   └── main.js         # DOM 연결 · 고정 타임스텝 루프
├── tools/spritegen/    # 픽셀맵 생성기(개발용 · 게임은 쓰지 않는다)
└── .github/workflows/deploy.yml
```

의존 방향은 아래로만 흐른다. `config.js`가 맨 밑이고 렌더러는 상태를 **읽기만** 한다.
게임 로직은 초당 60스텝 고정이라 모니터 주사율(60 · 120 · 144Hz)과 무관하게 같은 속도로 돈다.

## 그림 규칙

`src/sprites.js`의 `MAPS`가 프레임 정의 전부다. 한 글자가 한 도트이고, 글자의 뜻은
프레임이 쓰는 팔레트(`PAL`)가 정한다. 규칙은 셋뿐이다.

1. **머리가 큰 2등신.** 화면에서 실제로 보이는 크기는 한 뼘 남짓이라 사람 비례로 그리면
   얼굴이 뭉개진다. 몸을 줄이고 머리·모자를 키우면 멀리서도 실루엣이 읽힌다.
2. **면을 몇 개로 끊은 셀 셰이딩.** 재질마다 그늘 `d` · 기본 `m` · 밝음 `l` 세 단만 쓰고
   경계를 칼같이 끊는다. 계조를 부드럽게 깔면 90년대 에어브러시처럼 보인다.
3. **검은 외곽선 + 진한 접지 그늘(`D`).** 외곽선을 재질 색으로 물들이면 어두운 바닥에
   묻힌다. 검게 따고 발밑에 타원 그림자를 깔아야 그림이 배경에서 떨어져 나온다.

빛은 왼쪽 위 한 곳에서만 온다. 모든 그림이 같은 광원을 쓰므로 아틀라스 전체가 한 세트처럼
보인다. 좌우 대칭은 쓰지 않는다 — 대칭인 그림은 빛의 방향을 담지 못한다.

- **`art`** — 한 월드 단위를 몇 도트로 찍었는지(기본 1). 캐릭터·소품은 `art: 2`라
  같은 크기를 네 배 촘촘하게 그린 것이고, 화면에는 절반 크기로 그려진다.
  덕분에 그림을 다시 찍어도 이동 속도·판정 반지름 같은 게임 수치는 손대지 않는다.
- 프레임마다 `lift`(0/1)를 줄 수 있다. 발밑 기준으로 그리므로 걷는 동안 몸이 한 칸 뜬다.
- 아이템 아이콘은 공격·패시브 모두 같은 규격으로 통일했다(`flat`). HUD 슬롯이 가지런해진다.
- 배경은 어둡게 깐다. 바닥이 밝으면 캐릭터가 배경에 붙어 보인다. 타일은 덩어리로 뭉친
  얼룩과 짧은 풀결로 짜고, 맨흙 타일은 가장자리에 풀색 술을 물려 사각형 경계를 지운다.
- 굽기 전에 `validateMaps()`가 줄 길이와 팔레트에 없는 글자를 잡는다. CI에서도 같은 검사를 돌린다.

`buildSheet()`는 프레임을 높이순으로 선반(shelf) 배치해 캔버스 한 장에 채우고
`{ canvas, tinted, frames }`를 돌려준다. `tinted`는 피격 순간에 쓰는 흰 사본으로 좌표계가
같아 프레임 표를 그대로 쓴다. 통째로 하얗게 칠하면 형태가 사라지므로 외곽선은 검게 남긴다.

애니메이션은 `anim.js`의 클립(`frames` · `hold` · `loop`)으로 제어한다. 개체가 수백이라
적은 `Animator` 인스턴스 대신 자기 나이(`t`)만 갖고 `frameAt(clip, t)`로 프레임을 꺼낸다.

픽셀맵은 손으로 고쳐도 되지만, 같은 광원·같은 계조를 유지하려면 `tools/spritegen`으로
다시 굽는 쪽이 편하다(개발용 파이썬 도구 · 게임은 쓰지 않는다).

## 배포

`main`에 푸시하면 GitHub Actions가 픽셀맵을 검증한 뒤 GitHub Pages로 배포한다
(`.github/workflows/deploy.yml`). 빌드 단계는 없다.
